# First app: clock and remote

Open `index.html` locally to learn ordinary web rendering and remote key handling.
Left/Right toggle 12/24-hour format; OK pauses/resumes; Escape previews Back exit.
The code uses ES5 syntax and no network, storage, privileged APIs or Hub preferences.
It is an original teaching example inspired by the small-first-app progression in
[Democratizen](https://github.com/Vheissu/democratizen/tree/3406bf2922da926d22316bb75bee1732bbb70cee),
not a copy of its terminal, key-bearing package or service lifecycle.

This directory is unsigned and is not part of Hub's packaging manifest. A later
signed trial requires a reviewed disposable application identity and target trust,
ordinary app privileges only, and the shared signing/journal/recovery workflow.
Do not add this example to managed-package allowlists just to make installation
convenient. Preserve the prior signed Hub and physical Samsung Home route.
A browser preview does not test physical Back, Home, startup, standby or firmware.
After a separately authorized disposable-app trial, remove only that app using its
reviewed recovery path; no saved Hub preferences should change.
